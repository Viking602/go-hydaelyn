# v0.15.1

## Stream-rule interruption

- Add `agent.StreamRuleInterruptError` for host hooks that stop an open provider stream after a token-time rule match.
- Preserve already reported usage and optionally preserve the partial assistant message.
- Continue the agent loop so the host-owned turn-control queue injects the matched rule at the next deterministic model boundary.
- Record the interrupted provider step as `continue` with stop reason `aborted` instead of failing the durable run.
