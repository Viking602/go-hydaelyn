# Venat v0.14.1

Status: **Released**

Released on 2026-08-18.

v0.14.1 is the fail-closed and contract-alignment follow-up to v0.14.0. It
does not add a new control-plane surface.

## Fail-closed runtime

- Empty or unknown `PolicyDecision.Effect` is denied. Hosts that omitted
  `Effect` on an allow decision must set `api.PolicyEffectAllow` (or
  `policy.EffectAllow`) explicitly.
- `worker.AgentWorker` and `worker.TeamRunner` heartbeat immediately after
  lease acquire, then every `ttl/3`. A lost heartbeat fails closed instead
  of looking like a user cancel.
- `ReadyTasks`, `ReadyTasksContext`, `ActiveLeaseCount`,
  `ActiveLeaseCountContext`, `ResponseOutbox`, `ResponseOutboxContext`,
  `ResumeTokens`, and `ResumeTokensContext` now return `(T, error)`. Store
  failures no longer collapse to empty. `ResumeTokens` requires
  `SupportsListPending`.

## Process and sandbox I/O

- `tool/kit.ProcessTool` owns stdout and stderr pipes, waits concurrently
  with copies, then drains and closes so a descendant cannot hang
  `Execute`, including on Windows.
- `coding.Workspace` Lstats before open, rejects FIFOs and replacement
  write links, and uses `O_NOFOLLOW` / `FILE_FLAG_OPEN_REPARSE_POINT` so a
  swapped symlink cannot leave the workspace.

## Capability and run contract

- `hydaelyn.self.*` is reserved. `SaveCapability` returns
  `ErrCapabilityNameReserved` for that prefix.
- `api.Capability` adds `RequiresLease` and `RequiresPolicy` without
  removing `RequiresApproval`.
- `StartRunCommand` stamps `Run.AgentVersion`. `ListRuns` can filter by
  it. Replay restores the field. Empty versions remain valid for
  pre-stamp runs.
- `transport/mcp.ToolsFromCapabilities` ships. OpenAPI and CLI renderers
  stay deferred.

## Gates and toolchain

- Import-boundary checks cover production and test imports, including
  worker / packs / coding reverse edges and a named
  `coding/eval_regression_test.go` exception.
- `make verify` includes `architecture-check`.
- The pinned toolchain is Go 1.25.13.

See [`docs/migration.md`](../migration.md) for call-site changes.
