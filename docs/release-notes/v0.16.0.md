# Venat v0.16.0

Status: **Prepared release candidate** — 2026-08-28

v0.16.0 completes the v0.15 compatibility windows, removes speculative public
surface, hardens durable publication and worker recovery, and introduces the
experimental durable single-agent Harness/session contract.

## Breaking changes

- Remove the deprecated `memory/`, `flow/`, and `blackboard/` compatibility
  packages.
- Remove the intermediate `Runner.Admin()`, `Runner.Governance()`, and
  `Runner.Blackboard()` façades. Typed methods directly on `*Runner` remain.
- Remove `ReplayContext`, `ReadyTasksContext`, and `ResponseOutboxContext`.
- Remove the unconsumed `api.Artifact`, `ArtifactSelector`, `ArtifactStore`,
  `Projector`, and `UserTimelineProjector` contracts.
- Remove `api.Flow`, `Runner.RegisterFlow`, the redundant `workflow/` package,
  and the incomplete `multiagent.Graph`/`CompiledGraph` DAG surface.
  `Scheduler`/`SchedulerFunc`/`SequentialScheduler`/`Drive` remain the complete
  scheduling protocol; applications own specialized policies.
- Remove `multiagent.RouterScheduler`, `SupervisorScheduler`, voting helpers,
  `ObservedExecutor`, and unused collaboration reverse-mapping helpers.
- Remove `stream.Channel` and `stream.Merge`; host code owns pull adapters and
  fan-in.
- Make `Runner.RegisterAgent`, `RegisterTool`, and
  `RegisterToolForInvocation` return validation errors. `AgentProfile.Validate`
  is the shared preflight contract.
- Make `eval.Harness.RegisterAgent` return `error`, and make
  `worker.GovernedToolBus.ToolBus` return `(*tool.Bus, error)`.
- Expand `api.TraceStore` with `LoadTraceSpan` and `UpdateTraceSpan`, matching
  the existing `EndTraceSpan` runtime requirement.
- Remove `AgentFailure.EvidenceIDs` and
  `FailureKindInsufficientEvidence`.

See [Migration Notes](../migration.md) for replacements and host actions.

## Durable response publication

- Claim queued responses with an atomic `queued -> publishing` store transition
  before invoking the output gateway.
- Require `UserMessageStore.UpdateMessage` to reject concurrent stale status
  transitions; the storage conformance suite now checks a single claim winner.
- Leave every gateway error in `publishing`. A transport error does not prove
  non-delivery, so the runtime never automatically duplicates an uncertain
  external side effect.
- Add policy-authorized `ReconcileResponsePublication` for hosts to record a
  verified delivered or undelivered outcome.
- Count only gateway publications performed by the current outbox drain.

## Experimental agent Harness and session store

- Add `agent.Harness` for one durable, resumable conversation beside the
  capability-complete in-memory `agent.Engine`.
- Add `session.Storage` for atomic entry, usage, and register commits plus a
  process-local `session.Memory` implementation for development and tests.
- Use register-sequence CAS and renewable lane leases so two Harness instances
  cannot drive the same provider turn concurrently.
- Bound detached finalization, make repeated `Close` calls wait safely, and keep
  lifecycle locks out of remote storage I/O.
- Validate operation identity, reachable phase combinations, prompt ancestry,
  response reservations, and usage rows before resume.
- Terminate any tool-carrying provider stream as `tools_unsupported` before
  retry classification. Tools, hooks, budgets, output policy, sub-agents, and
  compaction remain intentionally unsupported by Harness.
- Keep the Harness/session JSON and exported surface Experimental until Engine
  capability convergence.

## Runtime and worker reliability

- Replace process-local runtime counters with monotonic UUIDv7 identifiers so
  durable lease and trace IDs remain unique across runtime restarts.
- Compose general and message-specific policy engines instead of letting one
  registration silently replace the other; union obligations and keep the
  stricter decision.
- Persist partial typed reports as `TaskPartiallyCompleted` events without
  releasing the active execution lease.
- Make event replay a pure state projection and remove inert side-effect
  counters.
- Back off exponentially only after fully failed worker batches, including a
  failed `ExecutionOutcome` returned without an error; reset after real
  progress.
- Wait for retry readiness before engine preparation, surface tool-registration
  and lease-release failures, preserve lease-loss heartbeat errors during
  cancellation, and bound single-run status-conflict retries.

## Architecture cleanup

- Remove unused internal auth, compaction, gate, middleware, plugin, program,
  security, error-wrapper, and governance helper packages with no production
  consumers.
- Update executable import boundaries for the new `session/` package and keep
  `agent -> session` as the only direct runtime-layer dependency.
- Amend ADR-016/020/021/025/026/027 to record the completed v0.16
  public-surface cutover; ADR-028 records the Experimental Harness/session
  invariants.
