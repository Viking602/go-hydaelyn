# Venat v0.14.2

Status: **Released**

Released on 2026-08-20.

v0.14.2 is a host-runtime follow-up to v0.14.1. It does not add a new
control-plane surface.

## Skill tools

- `hydaelyn_activate_skill` and `hydaelyn_read_skill_resource` return
  `IsError` tool results for invalid arguments, inactive skills, and
  undeclared resources, including `SKILL.md`.
- Those misses no longer abort the agent loop. The model sees the error
  text and can continue. `SKILL.md` remains the activation body, not a
  resource.

## Hashline recovery

- Stale hashline edits recover by current-file anchors instead of failing
  closed when a previously read snapshot has moved.

## Upgrade

```bash
go get github.com/Viking602/venat@v0.14.2
go install github.com/Viking602/venat/cmd/venat@v0.14.2
go mod tidy
```
