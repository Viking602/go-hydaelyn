# v0.15.3

## Typed MCP notifications and subscriptions

- Add `mcpcontract.SubscriptionClient` with `SubscribeResource` and `UnsubscribeResource`, implemented by the MCP client.
- Add the typed `mcpcontract.Notification` payload and `NotificationHandler` for host-registered notification handling.
- Preserve tool, prompt, and resource list-change, resource-update, logging, and progress events through the client contract.
- Keep elicitation and existing client lifecycle semantics unchanged when no handler is registered.
